# Mondo Imports Website

A responsive website for a wine importer, built with HTML, CSS and a little JavaScript.

Live demo: https://darknight-dot-coder.github.io/mondo/

## Features

- Hero section with navigation and contact number
- About Us and product sections
- Wine categories
- Wines by country, with tabs for Italy, France, USA, Australia, Canada and China
- Contact details and email signup in the footer

Built with HTML, CSS and JavaScript. Photos from Unsplash.
